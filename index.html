Pengaturan Server (Google Sheets)

Tempel URL Web App Google Apps Script Anda di sini supaya semua data (bank soal, data siswa, ujian, hasil) otomatis tersimpan ke Google Sheets dan bisa diakses secara real-time dari perangkat lain (HP, laptop, komputer lab, dst). Kosongkan & simpan untuk kembali ke Mode Lokal (data hanya di perangkat ini). Panduan membuat URL ini ada di README bagian "Setup Backend (Google Apps Script)".

Import dari Word (.docx)
Format tabel sama seperti template Excel — gambar yang ditempel langsung di kolom "Gambar"/Pertanyaan/Opsi otomatis terdeteksi & terunggah, tanpa perlu pilih file terpisah.

Soal bergambar (Excel): di kolom "Gambar" pada tabel, cukup ketik nama file gambarnya saja (mis. soal1.jpg) — lalu sebelum klik kartu Import, klik dulu "🖼 Gambar Pendukung" di kartu yang sama & pilih semua file gambar terkait sekaligus (boleh banyak file). Sistem otomatis mencocokkan berdasarkan nama file. Boleh juga langsung isi kolom "Gambar" dengan link gambar publik.

Soal bergambar (Word): tempel/sisipkan gambarnya LANGSUNG di dalam sel tabel Word (kolom "Gambar", atau bahkan di tengah teks Pertanyaan/Opsi) — saat diimpor, gambar tersebut otomatis terdeteksi & terunggah sendiri, tidak perlu lagi mengetik nama file atau memilih file gambar terpisah. Tombol "🖼 Gambar Pendukung" di kartu Word tetap bisa dipakai sebagai cara alternatif (cocok nama file) kalau kamu lebih suka begitu.

Soal yang dibuat tapi belum dipakai bisa diarsipkan supaya tidak mengganggu daftar aktif, lalu diedit & dikembalikan kapan saja lewat filter status "Arsip". Centang "Riwayat" untuk melihat soal yang sudah pernah dipakai di ujian mana saja.

🖥 Pemantauan Ujian

Pilih ujian untuk melihat siapa saja yang sedang mengerjakan/​sudah selesai, sisa waktu, jumlah soal yang sudah terjawab, dan jumlah pelanggaran anti-cheat -- lengkap dengan aksi untuk tiap siswa.

⏱ Tambah Waktu — memberi waktu ekstra ke satu siswa saja (mis. karena koneksi sempat putus), tanpa mengubah durasi siswa lain.
🧹 Hapus Pelanggaran — pelanggaran siswa itu langsung jadi 0; kalau sesinya sedang diblokir karena melewati batas pelanggaran, sesi otomatis dibuka lagi dan siswa bisa langsung melanjutkan dari soal terakhir yang dikerjakan, tanpa perlu mengulang ujian dari awal.
✅ Selesaikan Paksa — mengakhiri ujian siswa itu sekarang juga memakai jawaban terakhir yang tersimpan (autosave), lalu nilai langsung dihitung.
↺ Reset — menghapus sesi sepenuhnya; kalau siswa membuka ujian ini lagi, dianggap belum pernah mengerjakan sama sekali (soal diacak ulang, jawaban kosong, waktu mulai dari 0). Pakai ini hanya kalau memang perlu mengulang total dari awal.

Data Siswa

Kredensial akun siswa. Tambahkan satu per satu, atau impor massal dari file .xlsx/.csv.

Tambah Siswa Manual

Impor Massal

Format kolom (dari kiri ke kanan): nama, kelas, username, password. Kolom username dan password boleh dikosongkan — sistem akan membuatkan keduanya secara otomatis untuk baris yang kosong (username dari nama, password acak). Belum punya file? Klik "Unduh Template" dulu, isi contohnya di Excel/Spreadsheet, lalu impor kembali.

Isi kolom ini kalau semua siswa di file yang mau diimpor berasal dari satu kelas yang sama (mis. hanya kelas 9A) — nilainya akan dipakai untuk semua baris, menggantikan kolom "kelas" di file.

☁️ Koneksi Google Sheets

Hubungkan aplikasi ke Google Sheets (lewat URL Web App Google Apps Script) supaya data tersinkron ke semua perangkat, atau lepas koneksi untuk kembali ke Mode Lokal.

🔁 Sinkronisasi Paksa (lapisan kedua)

Data guru (soal/ujian/siswa) normalnya sudah langsung terkirim ke Google Sheets setiap kali disimpan, dan tiap tab menarik ulang data otomatis tiap beberapa detik saat Mode Server aktif. Dua tombol ini adalah lapisan cadangan manual untuk berjaga-jaga, atau untuk memindahkan data yang sempat dibuat saat masih Mode Lokal ke Google Sheets begitu Mode Server diaktifkan.

Menarik ulang seluruh Bank Soal, Ujian, dan Data Siswa dari Google Sheets saat ini juga (tanpa menunggu 8 detik), sekaligus menyimpan salinannya sebagai cadangan lokal di perangkat ini.

Mengirim seluruh data yang ada di penyimpanan lokal (Mode Lokal) perangkat ini — Bank Soal, Data Siswa, Ujian — ke Google Sheets yang sedang terhubung. Pakai sekali saat pertama kali pindah dari Mode Lokal ke Mode Server; mengulanginya akan membuat data ganda.
